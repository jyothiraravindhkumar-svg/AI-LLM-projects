# LangChain Fundamentals

Hands-on exploration of core LangChain building blocks.

**Covers:** LLM wrappers (OpenAI, HuggingFace Hub), `PromptTemplate`, `LLMChain`,
`SimpleSequentialChain`, `SequentialChain`, `ChatOpenAI`, and a custom `BaseOutputParser`.

## Run
```bash
pip install -r requirements.txt
cp ../.env.example ../.env   # then fill in your real keys
jupyter notebook langchain_fundamentals_exploration.ipynb
```
